
====================================================
BASIC LEVEL (1–15)
====================================================

1. What is Ansible primarily used for?
A. Database Management
B. Configuration Management and Automation
C. Web Development
D. Graphic Design

Answer: B

----------------------------------------------------

2. Which language is Ansible written in?
A. Java
B. Python
C. C#
D. Go

Answer: B

----------------------------------------------------

3. Which file format is used for writing Ansible Playbooks?
A. XML
B. JSON
C. YAML
D. CSV

Answer: C

----------------------------------------------------

4. Which command is used to check the Ansible version?
A. ansible --version
B. ansible version
C. ansible -v
D. ansible check

Answer: A

----------------------------------------------------

5. What is the default inventory file location in Ansible?
A. /etc/ansible/hosts
B. /etc/hosts
C. /ansible/inventory
D. /usr/ansible/hosts

Answer: A

----------------------------------------------------

6. Which protocol does Ansible use by default to connect to Linux hosts?
A. FTP
B. SSH
C. RDP
D. HTTP

Answer: B

----------------------------------------------------

7. Which command tests connectivity to all managed hosts?
A. ansible all -m ping
B. ansible ping
C. ansible test
D. ansible connect

Answer: A

----------------------------------------------------

8. What is an Inventory in Ansible?
A. Collection of Playbooks
B. List of Managed Hosts
C. Configuration File
D. Collection of Modules

Answer: B

----------------------------------------------------

9. Which keyword specifies the target hosts in a playbook?
A. target
B. server
C. hosts
D. machines

Answer: C

----------------------------------------------------

10. Which module is commonly used to install packages on Debian-based systems?
A. yum
B. apt
C. dnf
D. service

Answer: B

----------------------------------------------------

11. Which module is commonly used to install packages on RHEL 8+ systems?
A. apt
B. rpm
C. dnf
D. service

Answer: C

----------------------------------------------------

12. Which command runs an Ansible playbook?
A. ansible-run
B. ansible-playbook
C. ansible execute
D. ansible start

Answer: B

----------------------------------------------------

13. Which keyword is used to define a task name?
A. task
B. title
C. name
D. description

Answer: C

----------------------------------------------------

14. What is an Ansible Module?
A. Programming Language
B. Unit of Work Executed on Managed Nodes
C. Inventory File
D. YAML Parser

Answer: B

----------------------------------------------------

15. What is an Ansible Collection?
A. A group of managed hosts
B. A package containing modules, plugins, roles, and documentation
C. A list of playbooks
D. A configuration file

Answer: B
